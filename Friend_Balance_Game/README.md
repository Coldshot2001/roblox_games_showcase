This was an idea I had for a game akin to those two player games which required the players to do a task togheter (i.e. balance a log or an egg or whatever) and here you would instead be carrying your friend on top of you, and they would have to balance themselves so the two players wouldnt topple and walk off the map. However, after implementing the main mechanic, I felt like it wasn't really that fun / engaging so I dropped the project.
