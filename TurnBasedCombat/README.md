Another very old project with a turn based combat system, a gacha pull system and teams you build out of the units you own. The server side got reworked since the first upload: a battle turn only waits for the player who owns that battle, with a 30 second timeout that counts as a forfeit, and the Data remote only gives back the three keys the client actually reads instead of anything it asks for. Saves go through a DataStore keyed by user id, and units get rebuilt from the databases on load, since skills are functions and models are instances and neither one goes into a store. There are TestEZ specs next to the turn validation module covering the skill and target checks.
