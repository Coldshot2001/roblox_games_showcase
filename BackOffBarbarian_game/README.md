This is a recreation of the Castle Crashers' minigame "Back Off Barbarian", the version I have uploaded here is not the complete one and will not run if used, as it is only here for showcasing the most interesting parts of the code, and will be finished sometime soon. The grid side got cleaned up since the first upload: a cell is nil when its empty instead of a magic number, the enemy walk code stops when the round ends, and the input packet gets checked and clamped on the server before it touches the physics. Player data saves through a DataStore keyed by user id, and there are TestEZ specs next to the pathfinder for the open grid, the wall and the walled off case.
